The last one is off by default and that is not an oversight: a gateway may route an upstream name this list has never heard of — Maniple's own sends claude-sonnet-4-5 — so turning it on without checking breaks a working deployment.

ChatGPT plan

Answer with a ChatGPT subscription instead of an API key. Sign in with OpenAI once; every model routed to the plan is then answered by it, in whichever format the client asked in.

Open the OpenAI sign-in page
Anyone who can reach this port can spend this plan. Until now nothing here was worth taking; signed in, something is. Keep it on your own machine or a network you trust. Usage counts against the plan's own limits, and a limit reached comes back as a 429.

Anthropic API

Answer with a real Claude model, by API key. Every model routed here is answered by it, in whichever format the client asked in, tools and streaming included.

Requests on this route are billed to the key. Anyone who can reach this port can spend it, so keep it on your own machine or a network you trust.
It takes a key, not a Claude sign-in. Anthropic does not permit a tool to route requests through a Free, Pro or Max plan, so a subscription cannot be used here. Use an API key from the Claude Console or a cloud provider.

Faults

Things that go wrong on purpose: a stream that dies half way, a tool call that is not JSON, a connection reset. On every route, and reproducible from a seed.

All fault rules are paused. Nothing below will fire until they are resumed.

Fault rules

What a fault can do

A rule's match is the same condition language rules use. Gates are applied in order: skip the first after matches, then every everyth, until limit have fired, each with probability (drawn from seed, so a chaotic run can be run again). LLMSim's own functional cases are never faulted.

What an assertion can say

Capture

Requests are held in memory, bounded, and never written to disk. Assertions read what was held; redactions apply to what is shown, exported or returned.

Identity

Who sent a request is always read from the base URL — /run/<id>/agent/<name>/openai/v1 — which needs nothing of an agent platform but a URL. These rules read it from elsewhere, for a gateway that carries one through.

Credentials

Published accepts only the keys this file publishes. Registered adds credentials you register below. Any accepts anything and records which arrived — for witnessing what a gateway sends. A credential is kept as a fingerprint; the key itself is not stored.

Record & replay

Record a real run once — a Maniple session, say — and replay it exactly, offline and free.

Session

Recording keeps the model's answers — its text and tool calls — in cassettes/ on this machine, owner-only and not committed. It does not keep the requests, but an answer can quote one.

Cassettes

How a replay answers

A request is matched on what was asked and how far into the conversation it is — not on the whole request, which carries timestamps and tool output that never repeat. A recording made through one vendor's format replays through another's.

Strict is off by default because the last message is usually a tool's output, with timestamps in it. Off, a different one is still answered and counted as differs. Failing is the default because a run that has left its recording should be loud, not quietly talking to something else.

Chat

Talk to a model through LLMSim, on whatever route it is set to. It goes the same way a client's request does, and shows up under Requests.

System prompt, and a tool to offer

The model may call it, and the call is shown. It is not run, and no result goes back.

Functional tests

Send a model a prompt and say what must come back: the answer, the tool it calls, the status, how fast. It goes down whatever route that model is on. A case is a sequence of steps, run in order. Cases and plans are saved to llmsim.tests.json — commit it, or hand it over with Export.
